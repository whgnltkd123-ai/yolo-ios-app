2. 코드·상표·표시
Ultralytics iOS 소스와 YOLO 모델은 현재 AGPL 경로를 기준으로 준비한다. 전체 해당 소스, 수정 내역, 빌드/변환 스크립트와 필요한 모델 자료의 제공 범위를 확인하고 수령자가 실제로 접근할 수 있도록 해야 한다. 오픈소스 공개 자체만으로 학습 데이터의 권리가 해결되지는 않는다.
  https://www.ultralytics.com/license
  https://www.gnu.org/licenses/agpl-3.0.html
AGPL은 유료 판매를 일률적으로 금지하는 라이선스가 아니다. 이 앱은 사용자의 선택에 따라 무료·무광고로 한다. 소스 비공개로 바꾸면 별도 Enterprise 조건을 재검토한다.
ByteTrack은 MIT, Eigen은 MPL2/BSD, OpenCV 헤더·AndroidX·Kotlin은 Apache2, ONNX Runtime은 MIT 및 별도 third-party 고지. 전문을 앱 assets/licenses와 소스 배포에 포함한다. 실제 최종 의존성 목록과 대조한다.
YOLO 로고를 UI에서 제거하는 것과 저작권 고지를 삭제하는 것은 다르다. 원저작자·라이선스는 앱 안내 및 소스에 남긴다. 공식 Ultralytics 앱·공인 정확도·공인 300m 성능으로 소개하지 않는다. 제작자 문구는 앱 통합 제작 기여를 뜻하며 원 소스/데이터 저작자를 대체하지 않는다.
개인 이름·계급의 공개 표기 및 기관 명의 사용 권한은 게시자가 확인해야 한다. 기관의 공식 앱이라는 표현이나 상징은 임의로 추가하지 않는다.

3. 스토어 준비
- 현재 Android 구현은 Kotlin/CameraX + ONNX Runtime. iOS Core ML이나 Flutter 앱과 동일 실행 엔진이라고 주장하지 않음.
- targetSdk 36, arm64-v8a 및 x86_64, AAB 형식. APK/AAB의 모든 네이티브 라이브러리 ELF 16KB 정렬과 APK zipalign 검사를 통과했다. 실제 16KB 기기 실행 검증과는 구분한다.
  https://support.google.com/googleplay/android-developer/answer/11926878
  https://developer.android.com/guide/practices/page-sizes
- 광고·계정·분석 SDK·원격 푸시 서버 없음. INTERNET 권한 없음. 사진은 앱 저장소에 저장하고 사용자가 직접 내보내는 방식. 카메라·센서 사용과 보존/삭제를 개인정보처리방침에 설명.
- 최종 manifest/SDK와 Data safety를 대조해야 함. 오프라인 앱도 개인정보처리방침 URL과 앱 내 안내가 필요. 현재 privacy.txt는 게시자·연락처 미확정 초안이며 제출용 최종본이 아님.
  https://support.google.com/googleplay/android-developer/answer/10144311
- 앱명·고유 applicationId·게시자·문의 이메일·개인정보처리방침 공개 URL·Play 개발자 계정·업로드 서명키를 제출 전에 확정. 계정/결제/서명약정은 이 작업에서 진행하지 않음.
- 새 개인 계정에 해당하면 최소 12명, 연속 14일 비공개 테스트 후 프로덕션 접근 신청. 심사 통과 보장 없음.
  https://support.google.com/googleplay/android-developer/answer/14151465
- 실제 Android 기기 카메라·줌·FPS·발열·경보·갤러리·백그라운드 전환을 확인해야 함. iPhone 검증 결과를 Android 성능 증거로 재사용하지 않음.

4. 공개 전 남은 핵심
데이터별 미확정 권리 정리 → 모델 배포 권한 확정 → 완전한 대응 소스/고지 공개 → Android 실기기 검증 → 게시자/개인정보처리방침/서명 확정 → Play 테스트 트랙 → 공개 심사.
권리 제공자에게 연락하거나 사용 약정에 서명한 것으로 기록하지 않는다. 유료 라이선스를 구입하지 않았다.

5. 완료된 기술 검사
assembleDebug / bundleRelease / testDebugUnitTest / lintDebug 성공.
판정 경계·경쟁 클래스·비정상 점수·경보 단계 단위검사 4개 통과, Lint 오류 0개(권장 API/업데이트 관련 경고 14개 유지).
공개 변환 표본 3장에서 PyTorch/ONNX 출력 비교 통과. 모델/ZIP 해시 및 CRC 확인.
APK는 Android Debug 테스트 키, AAB는 게시자 서명 없음. 스토어 제출용 서명 완료로 표시하지 않는다.
새 Android 소스는 Kotlin/CameraX이며, 카메라·열·FPS·트래커 ID·경보의 실기기 검증은 미완료다.
